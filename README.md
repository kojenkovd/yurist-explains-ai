# Юрист объясняет | AI — V7

Цель: Telegram Mini App для обычных граждан РФ.

## Что входит
- премиальный dashboard с адаптацией под мобильный Telegram;
- анализ PDF/DOCX/TXT/изображений;
- несколько файлов в одной проверке;
- предварительный скрининг юридических рисков;
- генерация и редактирование документов;
- история и локальная статистика;
- юридический рентген и Telegram sharing;
- AI-контур через Cloudflare Workers (опционально, без ключа в браузере).

## GitHub Pages
Для первой публикации достаточно `index.html` и `background-wide.jpg`. В V7 основной CSS и JavaScript встроены в `index.html`, чтобы страница не зависела от отдельного файла стилей.

## Настройка платных услуг
Откройте `config.example.js`, переименуйте в `config.js` и укажите Telegram username. Этот файл не содержит секретов.

## Настройка AI backend
`worker.js` предназначен для Cloudflare Workers. Не храните API-ключи в GitHub. Для Workers используйте Secret/Binding в панели Cloudflare. См. официальную документацию Cloudflare Secrets.

## Юридическое позиционирование
Автоматический анализ является информационным скринингом. Он не должен выдавать предположение модели за подтверждённый юридический факт или заменять консультацию специалиста.
